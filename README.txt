MICROSOFT 365 & OFFICE GITHUB PAGES PROJECT

Contains 48 individual HTML articles based on the supplied titles.

FILES
- index.html: searchable homepage
- support.html: support information page
- style.css: shared stylesheet note (styles are embedded in each HTML page)
- articles/: 48 standalone HTML articles
- article-urls.txt: all article URLs
- sitemap.xml: XML sitemap for https://microsoftguide.github.io/

ARTICLE DETAILS
- Every article is at least 1,500 words; minimum verified count: 1746.
- Titles are preserved exactly as supplied.
- Slugs contain no serial numbers.
- Each article begins with its brand name: Microsoft 365 or Microsoft Office.
- Each article contains an individual title-based banner, illustration, and animated GIF embedded directly in its HTML.
- Sections include overview, features, benefits, steps, login/account considerations, troubleshooting, FAQs, and conclusion.
- No external links are included in article body content.
- Header navigation has Home, Login, and Support. Login and Support targets are #.

GITHUB UPLOAD
1. Extract the ZIP.
2. Upload the CONTENTS of the extracted folder to the repository root.
3. Keep index.html, support.html, sitemap.xml, article-urls.txt, and articles/ together.
4. Commit changes and check Settings > Pages.
5. After deployment, the sitemap will be available at https://microsoftguide.github.io/sitemap.xml.

Sitemap domain is set to the previously supplied subdomain https://microsoftguide.github.io/. If you publish this project on another subdomain, update sitemap.xml and article-urls.txt before publishing.
